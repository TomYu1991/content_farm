# 如何为个人博客选择静态托管：不懂编程也能上手的免费方案

如果你只是想有个地方写文章，不想研究服务器、数据库和运维，静态托管通常是最省心的选择。这篇文章面向完全不懂编程的新手，讲清楚三件事：静态托管是什么、几种常见免费方案有什么区别、以及具体怎么把博客发到网上。

## 一、先弄懂：静态托管到底在托管什么

静态网站就是一堆提前生成好的文件：HTML 页面、CSS 样式、图片。访问者打开网页时，托管平台只是把这些文件发给他，不需要运行程序、不需要查数据库。

这也是它便宜的原因：没有需要一直开着的服务器程序，平台的成本低，所以愿意提供免费额度。

典型的流程是这样的：

- 你用 Markdown 写文章；
- 用一个「静态网站生成器」把这些文字套进模板，生成一批 HTML 文件，这一步通常叫「构建」；
- 把这些文件交给托管平台；
- 平台负责保存文件、提供网址、配好 HTTPS。

免费的静态托管基本都自带 HTTPS 证书和 CDN 加速，这两项不需要你自己折腾。

## 二、选之前先回答四个问题

### 1. 你愿意碰命令行吗？

很多生成器（Hugo、Astro、Jekyll、Hexo 等）需要在电脑上敲一两条命令来生成网站。有些平台能在云端替你跑这些命令，有些则需要你本机生成好再上传。这一点直接决定你走哪条路线。

### 2. 要不要绑自己的域名？

平台的免费二级域名（比如 `xxx.pages.dev`）够用，但博客长期做下去，一般都会想换成自己的域名。选平台时提前确认：加自定义域名是否免费、HTTPS 是否自动签发、绑定的步骤复不复杂。

### 3. 你的读者主要在哪里？

这一条很关键，但很多教程会略过。

如果托管在境外平台，通常不需要备案，但国内不同网络、不同地区访问同一个站点的速度和稳定性差异可能比较大，建议你用手机流量、家里宽带、公司网络分别实测一下目标平台的示例站点再决定。

如果你打算用境内服务商或境内 CDN 加速，一般需要先给域名做 ICP 备案，要花时间和准备材料。具体规定请以服务商和当地要求为准，本文不展开。

### 4. 你能接受「免费但有上限」吗？

免费套餐几乎都有额度限制，比如每月构建次数、单个文件大小、文件总数。更重要的是搞清楚：超额之后是会停止构建、站点下线，还是自动扣费。这一条比额度数字本身更值得花五分钟确认。

## 三、几种常见方案，各自适合谁

下面是新手最常听说的几个，具体额度和条款经常调整，动手前请以官方文档为准。

**Cloudflare Pages**

- 适合：想要「免费 + 容易绑定自定义域名 + 改完自动部署」的人。
- 特点：免费套餐官方称不限带宽和请求数（构建次数等另有上限）；支持从 Git 仓库自动构建，也支持直接把生成好的文件夹上传上去，后者对不懂命令行的人很友好。
- 文档：https://developers.cloudflare.com/pages/

**GitHub Pages**

- 适合：已经在用 GitHub，或者愿意顺便学一点 Git 的人。
- 特点：把仓库里的文件直接发布成网站，免费，支持自定义域名和 HTTPS。配置项比 Cloudflare Pages 少一些，遇到问题时的排查手段也少一些。
- 文档：https://docs.github.com/en/pages

**Netlify**

- 适合：想快速试水、看重图形界面的人。
- 特点：老牌的静态托管服务，免费套餐包含构建和部署，也提供把文件夹直接拖进浏览器的上传方式。
- 文档：https://docs.netlify.com/

**Vercel**

- 适合：用现代前端框架、希望部署体验顺滑的人。
- 特点：对前端项目支持很好；免费套餐通常面向个人非商业用途，如果你打算靠博客接广告或做业务，务必先读清楚条款。
- 文档：https://vercel.com/docs

**对象存储 + CDN（阿里云 OSS、腾讯云 COS 等）**

- 适合：想用境内节点、愿意折腾配置和付费的人。
- 特点：按量计费，费用通常要自己算清楚流量成本；配置比上面几个麻烦，且境内使用一般涉及备案。不建议作为第一次搭建的首选。

> 小结：如果只想快点看到自己的博客上线，**Cloudflare Pages** 或 **GitHub Pages** 通常是最短的路径。想要「静态网站 + 免费托管」这两个条件同时满足，它们也是最常被推荐的两个。

## 四、两条具体路线，照做就行

### 路线 A：不碰命令行，直接上传文件夹

这条路线适合完全不想装开发环境的人。前提是你得先有一个「生成好的网站文件夹」。这一步是新手最容易卡住的地方，常见做法有两种：

- 用带图形界面的桌面工具写文章并导出静态站点（例如 Publii 这类软件，具体支持的平台和导出方式请以它官网说明为准）；
- 或者找一个生成器的主题模板，照官方「快速开始」跑一次构建命令，得到一个文件夹。

拿到文件夹后，以 Cloudflare Pages 为例（界面可能变动，以官方文档为准）：

1. 注册 Cloudflare 账号；
2. 进入控制台，找到 Workers & Pages，选择创建 Pages 项目，用「上传资源」的方式；
3. 给项目起个名字，这个名字会变成你的网址前缀；
4. 把整个文件夹拖进去上传——注意文件夹里必须有一个 `index.html`，它是网站首页；
5. 部署完成后访问平台给你的网址，确认页面正常；
6. 以后更新文章，就是重新生成文件夹、再上传一次。

这条路线的好处是门槛低，代价是每次更新都要手动上传。

### 路线 B：接上 Git，让平台自动构建（长期更省事）

如果你愿意学一点点 Git，推荐走这条。之后你只要把文章推送到仓库，网站会自动更新。

1. 在 GitHub 上新建一个仓库，把博客源码放进去；
2. 在 Cloudflare Pages 里选择「连接到 Git」，授权并选中这个仓库；
3. 填写构建命令和输出目录。常见组合如下（请对照你所用生成器的官方文档确认）：
   - Hugo：构建命令 `hugo`，输出目录 `public`；
   - Astro：构建命令 `npm run build`，输出目录 `dist`；
   - Jekyll：构建命令 `jekyll build`，输出目录 `_site`；
   - Hexo：构建命令 `hexo generate`，输出目录 `public`；
4. 保存并部署，第一次构建成功后，以后每次推送都会自动重新构建。

如果第一次构建失败，先看平台的构建日志里第一条报错，通常是构建命令或输出目录填错了。

### 绑定自己的域名

不管走哪条路线，加域名的大致步骤是一样的：

- 在域名注册商处购买域名（价格因后缀和注册商而异）；
- 在托管平台的项目设置里添加自定义域名；
- 按提示配置 DNS。域名 DNS 已经托管在 Cloudflare 的情况下通常几步就能完成；其他情况按提示在域名商处添加 CNAME 等记录；
- HTTPS 证书一般由平台自动签发，不需要自己购买。
- 提醒：如果以后打算换成境内服务器或境内 CDN，通常需要提前完成备案，记得把这个时间成本算进去。

## 五、动手前一定要看的几个坑

- **超额行为**：免费额度用超之后，是停止构建、网站下线，还是自动扣费？先确认。
- **商用限制**：部分免费套餐只允许个人非商业用途，博客一旦接广告或带货就可能触碰条款。
- **数据归属**：文章源码要留在自己能拿到的地方（本地 + 一个代码仓库），不要只存在平台的后台编辑器里。平台改条款或停止服务时，你才不会被动。
- **构建限制**：频繁改文章的人容易撞上每月构建次数上限，选平台时留意。
- **文件限制**：单文件大小和文件总数一般都有上限，图片多的博客要提前看。
- **迁移成本**：绑定自有域名能让换平台的代价小很多，因为读者不需要重新记网址。

## 六、一句话决策清单

- 完全不想学任何工具：用图形界面工具生成站点，再走 Cloudflare Pages 的直接上传；
- 愿意学一点点 Git：GitHub 仓库 + Cloudflare Pages 自动构建；
- 已经在用 GitHub：GitHub Pages 最省事；
- 将来想接境内加速：先把备案的时间和材料准备好。

## 写在最后

先跑通一个「最小可发布」的版本——一篇文章、一个能打开的首页，然后再去折腾主题、评论和统计。托管平台换来换去成本并不高，真正难补的是内容，所以记得定期备份。
